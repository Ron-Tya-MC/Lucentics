# **Lucentics**

Lucentics is a Minecraft Java Edition 1.21.1 / NeoForge mod themed around light and color.  
Lucenticsは、光と色をテーマとしたMinecraft Java Edition 1.21.1 / NeoForge向けのMODです。

Harness sunlight and light in 16 colors, explore the world, and use a variety of devices to unravel its mysteries.  
太陽光と16色の光を操り、世界を探検し、様々な装置を利用して、世界の謎を解き明かしましょう。

## Devices / 装置

Build various kinds of devices and create numerous kinds of materials.  
様々な装置を組み立て、様々な素材を生み出しましょう。

Every device is powered by light.  
全ての装置は光の力によって動作します。


## Crafting with Light / 光によるクラフト

Of course, the crafting devices need light to run as well.  
クラフト装置を動かすのにも、もちろん光が必要です。

Most crafting can’t be completed with a single block. Combine blocks with beams of light to carry out rituals.  
ほとんどのクラフトは1ブロックで完結しません。ブロックと光の帯を組み合わせて、儀式を進行しましょう。

## Prisms / プリズム

Prisms are small hard workers that do the job for you.  
プリズムはあなたの代わりに働いてくれる、小さな働き者です。

Place them along a beam’s path and each one acts as a single component, repeating a set action such as breaking, placing, or attacking.  
光路上に並べることで一つのパーツとして振る舞います。破壊、設置、攻撃...など決められた動きを繰り返します。

## Combining Prisms and Automation / プリズムの組み合わせと自動化

Combining multiple prisms lets you handle more complex operations.  
プリズムを複数組み合わせることで、より複雑な動作に対応できます。

Transport items and fluids from one place to another, break a block and place it somewhere else, and automate all sorts of processes depending on how you combine your prisms.  
アイテムや流体を一方からもう一方へ搬送したり、ブロックを壊してそれを別の場所に置いたり、プリズムの組み合わせ次第で様々な工程を自動化できます。

## In-Game Guide / ゲーム内ガイド

An in-game guidebook powered by Patchouli is included.  
Patchouliによるゲーム内ガイドブックを実装しています。

You can also check every recipe in the mod using JEI and similar mods. Information from some devices can be read using Jade.  
また、JEI等を用いてMOD内の全てのレシピを確認できます。一部の装置の情報はJadeを用いて読み取ることができます。
